
# PRO AUDIO MASTER ACADEMY

A bilingual professional audio engineering learning platform.

## Features

- Arabic and English interface
- Audio engineering curriculum
- Structured lessons and quizzes
- Student progress tracking
- Interactive analog mixer training lab
- Live event production topics
- Sound system engineering topics
- Responsive design for desktop and mobile

## Run locally

1. Download or clone this repository.
2. Open `index.html` in a modern browser.
3. Start learning.

No build tools are required for this initial version.

## Publish on GitHub Pages

1. Create a public GitHub repository named:
   `PRO-AUDIO-MASTER-ACADEMY`
2. Upload `index.html` and `README.md` to the repository root.
3. Open Settings.
4. Select Pages.
5. Under Build and deployment, select Deploy from a branch.
6. Select the `main` branch and `/ (root)`.
7. Save and wait for deployment.

## Important

This is the initial educational platform foundation.

The mixer lab is a simplified educational model, not a real audio processor or a model-specific Dynacord console simulator.

Model-specific equipment training must be verified against the exact manufacturer's documentation.

Student progress is currently stored locally in the browser.
